Friends of the Cesium Chinese Website

Jul 15, 2019
2 minute read
中文

We have now launched Knowledge Planet - Friends of the Cesium Chinese Website.

Note: Please think carefully before joining. Once paid, no refunds will be given. The following content is provided on a best-effort basis. 1. One technical exchange session per month (primarily Cesium-related), with source code provided.
2. Each person gets 5 free questions per week (Cesium, data visualization, and other technical topics).
3. Resume review and job referrals.
4. Career planning available for an additional fee.

The tentative exchange topics are as follows: [Give a man a fish and you feed him for a day; teach a man to fish and you feed him for a lifetime. The key goal is to help everyone develop the ability to independently research and develop related frameworks**]; we hope this will be helpful to you.

  1. Considering everyone’s actual situation, we may briefly cover: operating systems, computer networks, HTML/CSS/JavaScript, object-oriented programming, and basic principles of 3D digital earth.

  2. Being able to use basic Git commands, download code from open-source communities, and run Cesium.

  3. Loading and manipulating images, terrain, and models in Cesium.

  4. Whether you can crawl your own tile map data; how to write lightweight crawling tools.

  5. How to build your own GIS data server through GeoServer, and 2D data display with OpenLayers.

  6. Cross-platform web, human-computer interaction events in Cesium, and how to achieve synchronization across browsers or devices within a local network.

  7. Other topics that may be covered: Cesium with Echarts and Vue, other GIS systems, and some data visualization content.
