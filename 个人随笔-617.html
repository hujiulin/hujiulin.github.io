[年终总结]我的2014

Jan 11, 2015
阅读时长: 3 分钟
English

2014年，对于我来说，感觉过得很慢，又过得很快。这一年一只脚已经进入了社会，就等另一只脚的迈入。我将对自己的2014年进行一个“大事”盘点。 整理归档好过去，拥抱一个新的未来。

  1. 看了一些书籍。

    1.1 吴晓波的《大败局》全集

    1.2 南派三叔的《盗墓笔记》

    1.3 过了一次《编程之美》

    1.4 过了一次《程序员面试宝典》[为了找工作]

    1.5 看了部分《Effective C++》

    1.6 Accept 所有 Leetcode题目。

  2. 4月17日，怀着激动的心情进入微软亚洲研究生创新工程组实习。

    这是我人生难得的一次机会，误打误撞进去了顶级的技术及研究公司（研究院），在里面写了半年的代码，这种内外的成长，对我造成了强大的冲击，在之前我觉得自己还是比较能写代码的，后来接触最多的两个词是：规范，为什么。

    回头想想，MSRA的经历将影响我一生，在这里我衷心的感谢我的 Mentor: Genduan 以及 Chaowa 对我的帮助。

  3. 作为一名 Dev，与2014年5月，找到了自己的女友，是一件如此高兴的事，终于可以面向对象编程了。

  4. 找工作阶段

    这段时间辗转难眠，那段时间让我想起了 PennyJob 的运营者梁斌的一篇博文：百司不录。

    虽然断断续续，有一些 OFFER，但是压力之大，可能也是如人饮水吧。

  5. 10月8日，猿题库实习。

    这是一家创业公司，一群很有理想，很厉害的人，在一起。想做一些很酷的很颠覆的事。我的 Mentor 是一位 IOS 界的大牛 —— DevTang。这家公司带给我的是一种耳目一新的感觉，一个初入江湖的人，在一家创业公司里面，能看到的，接触到的，听到的，学到的那么多技术之外但是又与技术息息相关的知识，受用终生。

  6. 旅行

    去了十渡。｜去了北戴河。｜ 去了天津。｜去了青岛。｜ 去了香港。

接下来？我离职时，我师兄问我，接下来打算干嘛？是啊，接下来打算干嘛？我也回答不了，但是我希望我的2015年能做下列清单中的 Items：

  1. 旅行

    1.1 去哈尔滨 [Get √] | 1.2 去西藏 | 1.3. 去云南 [Get √]

  2. 坚持在自己的个人博客上完成技术的学习和分享，写出高质量的博客 [Get√，应该能坚持下来，不过质量慢慢提高吧]。

  3. 坚持写出更高质量的代码，并在 GitHub 上有所贡献，希望自己的某个项目能够获得100个 Star。

  4. 开源一款基于 ThinkPHP 的门户系统 [Get√，不过未开源]。

  5. 思考自己的未来，专注的研究某项技术。

  6. 看一些像样的书籍：

    6.1 吴军的《文明之光》

    6.2 [加] 马尔科姆•格拉德威尔 的《逆转》

    6.3 看完《格鲁夫给经理人的第一课》

    6.4 看完《Effective C++》

    6.5 《怪诞行为学》 [Get√]

  7. 好好学学英语，争取出国自助游。

  8. 从头做一次 leetcode 中的所有题目。
